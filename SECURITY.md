# Security policy

## Supported versions

Security fixes are applied to the latest published minor release.

| Version | Supported |
| --- | --- |
| 1.5.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/xDecisionSystems/openNASR/security/advisories/new).
Do not include sensitive details in a public issue.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. Maintainers will acknowledge the report, investigate it, and
coordinate disclosure and a release as appropriate.

This library is not an operational aviation data service. For aviation safety
concerns, consult current official FAA publications and services.
