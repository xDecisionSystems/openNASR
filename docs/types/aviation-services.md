# Aviation services

openNASR provides focused data types for air traffic facilities, radar,
communications, frequencies, weather observations, flight service stations,
and FAA location identifiers. Each child page documents the source table,
complete lookup key, related records, and generated API.

```{toctree}
:maxdepth: 1

location-identifier
```

These are local record and repository APIs. They read the selected FAA cycle
and do not contact an external service.
