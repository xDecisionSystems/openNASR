# Military data

openNASR models airport-linked military operations and published military
training routes as separate domain types. Each child page documents its FAA
identity key, relationships, ordered records, and generated API.

```{toctree}
:maxdepth: 1

military-operation
military-training-route
```

Military training route points retain distinct point identifiers and display
sequences. Airport-linked operations use the complete FAA site key.
